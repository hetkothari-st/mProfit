# Fund detail — Detailed calculations

`F-MF-020` · Live · Roles: [R-PLUS](../roles.md#r-plus), [R-FAMILY](../roles.md#r-family), [R-PRO](../roles.md#r-pro)

**What it does:** The **Detailed calculations** tab shows: the **Fund score** card (composite, stars, rating status, risk-o-meter, category universe, median and top-quartile scores, expandable pillar breakdown with **Input**, **Value**, **Category median**, **Percentile**, **Weight**, **Across horizons**); **Performance and risk** with horizon tabs **1Y 3Y 5Y 7Y 10Y** and metric groups **Returns**, **Risk**, **Risk-adjusted**, **Consistency** (plus rolling distribution, drawdown, calendar-year table and category percentiles); the findings block ([F-MF-021](F-MF-021.md)); portfolio characteristics (holdings, top 10 weight, HHI, effective holdings, cash, active share, turnover, style drift, market cap, sectors, top holdings, debt metrics); and **Fund facts** (TER, category median TER, AUM, manager tenure, AMC, SEBI category, ISIN, benchmark, inception, minimum SIP, status).

**Why it exists:** Inferred from behavior: the full evidence behind the Overview for readers who want every metric.

**Where to find it:** Fund page → **Detailed calculations** tab.

**Who can use it:** [R-PLUS](../roles.md#r-plus), [R-FAMILY](../roles.md#r-family), [R-PRO](../roles.md#r-pro).

**Steps**
1. Click **Detailed calculations**.
2. Click a horizon tab ([S-MF-011](../settings/mutual-funds.md#s-mf-011)); the metrics and percentiles switch to that horizon.
3. Expand a pillar in the score card to see its inputs.

**Controls**
| Control (exact label) | Type | What it does | Disabled / hidden when |
|---|---|---|---|
| **1Y**, **3Y**, **5Y**, **7Y**, **10Y** | Tabs | Select horizon | — (all five always shown) |
| Pillar row | Toggle | Shows the pillar's inputs | Only when a score exists |

**Fields and rules:** Not applicable — view only.

**Settings and toggles here:** [S-MF-010](../settings/mutual-funds.md#s-mf-010) **Overview / Detailed calculations**; [S-MF-011](../settings/mutual-funds.md#s-mf-011) **Horizon tabs** — defaults to the shortest horizon with data, else 3Y; not saved.

**Results:** None; read-only.

**Errors and troubleshooting**
| Message / symptom | Cause | Fix |
|---|---|---|
| **No NY-year record** | No metrics at that horizon ("… it is not a return of zero.") | Pick another horizon |
| **No category ranking at this horizon** | No peer ranks at that horizon | None |
| **No portfolio disclosure on file** | No holdings snapshot | None |
| **Relative metrics are not available** | No benchmark-relative data | None |

**Limitations:** All five horizon tabs show even when empty, by design.

**How it works:** Same single read as [F-MF-018](F-MF-018.md). Metrics, peers and scores are produced by the nightly and monthly jobs ([F-MF-023](F-MF-023.md)).

**Related features:** [F-MF-018](F-MF-018.md), [F-MF-021](F-MF-021.md), [F-MF-023](F-MF-023.md).
