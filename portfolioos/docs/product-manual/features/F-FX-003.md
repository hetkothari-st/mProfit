# FX pair positions

`F-FX-003` · Live · Roles: [R-FREE](../roles.md#r-free), [R-PLUS](../roles.md#r-plus), [R-FAMILY](../roles.md#r-family), [R-PRO](../roles.md#r-pro), [R-MANAGER](../roles.md#r-manager)

**What it does:** The **FX pairs** tab lists currency-pair positions (for example USDINR or EURUSD) recorded as transactions, with live value from the stored rates, the summary strip and the transactions table, and below them the realised P&L table ([F-FX-004](F-FX-004.md)).

**Why it exists:** Tab description: "Currency pair positions (USDINR, EURUSD, …). Speculative business income — bypasses CG FIFO."

**Where to find it:** **Asset Classes → Forex → FX pairs**.

**Who can use it:** [R-FREE](../roles.md#r-free), [R-PLUS](../roles.md#r-plus), [R-FAMILY](../roles.md#r-family), [R-PRO](../roles.md#r-pro); [R-MANAGER](../roles.md#r-manager).

**Steps**
1. Click **FX pairs**. Click **Add** to record a buy or sell in the shared transaction form ([D-FX-003](../dependencies.md#d-fx-003)). The pair is identified by a code such as USDINR or EURUSD, stored in the transaction's ISIN field.
2. Edit or delete transactions from the table.

**Controls**
| Control (exact label) | Type | What it does | Disabled / hidden when |
|---|---|---|---|
| **Add** | Button | Opens the transaction form for FOREX_PAIR | — |
| Edit / delete on rows | Buttons | As in other asset pages | — |

**Fields and rules:** As the shared transaction form ([D-FX-003](../dependencies.md#d-fx-003)).

**Settings and toggles here:** None.

**Results:** Positions appear with live value.

**Errors and troubleshooting:** As the shared asset page.

**Limitations:** Live value on this tab is quantity × the base currency's INR rate for both 3-letter and 6-letter codes; a pair with no INR rate for its base shows no live value.

**How it works:** Shared asset page with asset class FOREX_PAIR; the server values a 6-letter pair at base→quote and converts to INR.
