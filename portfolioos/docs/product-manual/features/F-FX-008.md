# TCS credits

`F-FX-008` · Partial · Roles: [R-FREE](../roles.md#r-free), [R-PLUS](../roles.md#r-plus), [R-FAMILY](../roles.md#r-family), [R-PRO](../roles.md#r-pro), [R-MANAGER](../roles.md#r-manager)

**What it does:** When TCS credits exist, the **TCS credits** table lists them (FY, collector, TAN, amount).

**Why it exists:** To keep the TCS collected on remittances for the tax return (inferred from the fields).

**Where to find it:** **Asset Classes → Forex → LRS & TCS**, below remittances.

**Who can use it:** [R-FREE](../roles.md#r-free), [R-PLUS](../roles.md#r-plus), [R-FAMILY](../roles.md#r-family), [R-PRO](../roles.md#r-pro); [R-MANAGER](../roles.md#r-manager).

**Steps:** Not applicable — view only.

**Controls:** None.

**Fields and rules:** Not applicable.

**Settings and toggles here:** None.

**Results:** None.

**Errors and troubleshooting:** None.

**Limitations:** There is no screen to add, link or delete a TCS credit, so the table stays empty in normal use; the remittance form doesn't link to a credit.

**How it works:** `GET /api/forex/tcs`; create and delete exist only in the API ([F-FX-009](F-FX-009.md)).

**Related features:** [F-FX-007](F-FX-007.md), [F-FX-009](F-FX-009.md).
