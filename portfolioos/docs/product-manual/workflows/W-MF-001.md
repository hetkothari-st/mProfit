# Import your mutual fund history from a CAS PDF

`W-MF-001` · Mutual Funds

**Goal:** Get every mutual fund transaction from a CAMS / KFintech CAS into EveryPaisa.
**Who:** [R-FREE](../roles.md#r-free), [R-PLUS](../roles.md#r-plus), [R-FAMILY](../roles.md#r-family), [R-PRO](../roles.md#r-pro) ([R-MANAGER](../roles.md#r-manager) imports into the managed person's data).
**Before you start:** Download your CAS PDF (or request one with [W-MF-002](W-MF-002.md) / [W-MF-003](W-MF-003.md)).

| # | You do | The app does |
|---|---|---|
| 1 | Open **Asset Classes → Mutual Funds**, click **Import CAS PDF** | Scrolls to **Automated CAS Import** |
| 2 | Drop the PDF or click **Choose file** | Toast "CAS uploaded — parsing in background. Status will update below."; **Recent imports** shows Pending/Processing |
| 3 | Wait (10–30 seconds for large files) | Status polls every 2 seconds; holdings and transactions refresh when done |
| 4 | If **Needs password**: click it, enter the PDF password | "Password accepted — reprocessing" |
| 5 | Check the row count and the holdings table | Holdings show units, value and P&L ([F-MF-001](../features/F-MF-001.md)) |

**Success:** Status **Completed**, rows "N/N rows", funds appear in the holdings table.
**If something goes wrong**
| Symptom / message | Why | How to recover |
|---|---|---|
| **Failed** or **Partial** | Some rows could not be parsed | Click **View**; fix via the Import page ([D-MF-003](../dependencies.md#d-mf-003)) |
| "CAS confirmed — no MF transactions in this period. …" | The statement's date range has no MF transactions | Request a wider range ([W-MF-002](W-MF-002.md)) |
| Funds listed without NAV | NAV not yet loaded for the scheme | Wait for the nightly update at 22:00 IST |

Continues on the Import page for error handling ([D-MF-003](../dependencies.md#d-mf-003)).
